# Keyboard shortcuts

Inscribe keeps the main workspace actions available from the keyboard. On macOS, the primary modifier is Command; the shortcuts below use Ctrl for the Windows/Linux notation.

Shortcuts yield to focused editors, inputs, controls, the embedded terminal, and open modals/overlays by default. Ctrl+` is intentionally global so the terminal can always be toggled. Ctrl+V yields to normal paste in editable fields.

| Shortcut | Action | Context |
| --- | --- | --- |
| `Ctrl+V` | Paste Intake | Replaces Intake from the clipboard outside editable or interactive controls. Normal paste remains available in editors, inputs, and the embedded terminal. |
| `Ctrl+O` | Open Repository | Opens the repository picker outside editable or interactive controls. |
| `Ctrl+P` | Open Recent Repositories | Shows and focuses the recent repository list outside editable or interactive controls; an empty state offers Open Repository. |
| `Ctrl+Shift+O` | Open Intake File | Loads a Markdown file into Intake outside editable or interactive controls. |
| `Ctrl+\`` | Toggle Terminal | Shows or hides the repository terminal from any context. |
| `Ctrl+/` | Show Keyboard Shortcuts | Opens the in-app shortcut reference outside editable or interactive controls. |
| `Ctrl+↵` | Primary Action | Runs the currently enabled primary workspace action—Parse, review a partial V2 preview, or apply the current V1/V2 review. Does nothing when unavailable. |

The in-app reference is available from the keyboard icon in the workspace toolbar or with `Ctrl+/`.
